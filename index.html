Configure and download your server files instantly.

⚙️ Server Configuration

Leave as filename if in default Documents folder, otherwise use full path (e.g., C:\Users\Name\...\Worlds\MyWorld.wld)
If the server crashes or stops, it relaunches automatically after a few seconds.

📜 Generated Launcher (.bat)

Place the downloaded file(s) in your Terraria Server folder.

📖 How to Use

  1. Install Terraria Server from the "Tools" section of your Steam Library.
  2. Configure your settings on the left. The preview on the right updates automatically.
  3. Click Download .bat and place the file inside your Terraria Server installation folder.
  4. Double-click the downloaded StartServer.bat file to launch your server!
  5. To let friends join: You must Port Forward port 7777 (TCP/UDP) in your router settings to your PC's local IP address.
